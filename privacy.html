GPT Images to Tripo3d — Privacy policy

Effective November 18, 2026. Publisher: multipliedtwice.

GPT Images to Tripo3d connects text prompts, generated images, Tripo Studio models and local FBX files. The extension has no developer-operated backend, advertising, analytics or telemetry.

Information used

The extension processes the prompts you enter, generated images, reference images in your selected folder, model exports, and relevant page content in your selected ChatGPT and Tripo tabs. It reads tab titles and URLs to identify these tabs, and reads generation status, model identifiers, export links and displayed credit information to operate the queue.

Where information goes

When you start the prompt queue, your prompts are submitted to ChatGPT using your signed-in account. When you start the model queue, reference images are uploaded through Tripo Studio using your signed-in account. Generated images and exports are downloaded from the services or their file hosts. These services receive the information needed to process your requests under their own terms and privacy policies. The extension does not send your prompts, files, browsing data or account credentials to the extension developer.

The extension uses your existing website sessions. It does not ask for passwords or API keys.

Optional local MCP control

If you run and configure the optional local helper, the extension connects to it at 127.0.0.1. Your chosen MCP client can request queue state, prompts, conversation URLs, filenames, output status, settings, and relevant service-tab titles and URLs. It can submit queue commands through the helper. The helper transfers generated images, reference files, model exports and recovery records between the extension and the output directory you configure with RUNNER_OUTPUT_DIR. A configured directory replaces the Chrome folder picker for this mode.

The extension does not send this information to a model provider itself. Your chosen MCP client may send information it receives to its model provider or retain it according to that client's settings and privacy policy. Review those settings before enabling agent control. The local helper has no developer-operated server or telemetry.

Local storage and files

Chrome extension storage keeps settings, selected tab information, prompt text, queue status, conversation URLs and output filenames. In manual mode, IndexedDB stores the directory handle for your selected folder. In configured-helper mode, the helper uses the local directory path supplied in its environment configuration. The selected folder contains reference images, generated images, exported models and a .tripo-runner folder with recovery records and staged exports. Prompt text may form part of a generated image filename.

A processed root reference image is removed only after its copy and model export have been verified in an output folder. Keep your recovery files if you need to resume unfinished work.

Permissions

Storage retains settings and queue state. Tabs identifies and controls the ChatGPT and Tripo tabs used for the workflow. Scripting reconnects the bundled automation scripts to those supported pages. HTTPS host access lets the extension download signed model exports from file hosts whose addresses can vary. Automation scripts run only on the supported ChatGPT and Tripo pages. Manual folder access is limited to the folder you choose and approve in Chrome. Optional MCP mode uses localhost host access to communicate with the helper and access only its configured output directory. The alarms permission checks for that local helper every 30 seconds and opens or reconnects the control tab when it is available. The helper requires the configured extension identity and authenticates requests with a process token; it binds only to the local computer.

Retention and deletion

Use Clear finished to remove saved and failed prompt rows from the extension queue. Removing the extension clears its extension storage and stored directory handle; it does not delete files in your selected folder or conversations and models in your service accounts. Delete local files yourself when you no longer need them. Removing the extension does not remove a separately downloaded helper or erase data retained by an MCP client or its provider; manage those separately. Manage ChatGPT conversations and Tripo models through the respective services.

Data use

Information is used only to provide this workflow. The extension does not sell user data, use it for advertising, transfer it for unrelated purposes, or use it to assess creditworthiness or lending eligibility. Use and transfer of information adhere to the Chrome Web Store User Data Policy, including its Limited Use requirements.

Contact

For questions or requests, open an issue at the project support page. Do not include private prompts, signed export URLs or account information in public issues.
